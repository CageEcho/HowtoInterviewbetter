# 面试复盘 Skill
## 输入清单（缺则先提示补齐）
转写分享链接或逐字稿、公司/岗位（可脱敏）、轮次、日期。
## 步骤
1. 读逐字稿；ASR 错字结合上下文核对，不确定处标出。
2. 按 `templates/复盘文档模板.md` 输出；占位栏原地填写，不留「待补充」。
3. 逐题：原回答摘录→问题所在（这两栏不加框）→三色高亮块，格式严格照模板：
   - 🟢 绿框 `background-color="light-green" border-color="green"`：建议回答 / 可直接照念的口播，第一人称、去掉分类标签；话术补丁也用绿框。
   - 🔴 红框 `background-color="light-red" border-color="red"`：概念解释、底层原理、避坑红线。
   - 🟡 黄框 `background-color="light-yellow" border-color="yellow"`：深挖追问接招与反问话术。
   - 不支持高亮块的文档工具，用 🟢/🔴/🟡 引用块代替，颜色含义不变。
4. 按 `book/05-打分口径.md` 打分，给合格率、完全到位率、高光、卡点。
5. 每个卡点给一条话术补丁；检查数字口径是否前后一致。
6. 列出收尾动作：面试表（一岗一行，只改状态）、问题汇总（只记问题）、话术文档。
7. 可建议用户按 `book/09` 的方法用 AI 做高阶面试陪练。
## 一键建飞书结构
用户说「帮我建面试复盘飞书结构 / 初始化面试记录表 / 搭面试复盘知识库」时，不做复盘，改按 `feishu-setup.md` 执行：先问姓名、学号（可选）、space_id → dry-run 给计划 → 用户确认后创建（同名跳过）→ 回读核对 → 输出链接清单。参考脚本 `scripts/setup_feishu.py`，字段定义 `templates/面试表Bitable字段定义.json`。不要自动放开分享权限。
## 约束
只依据手册与用户材料作答；分享内容须去掉真实姓名、公司、薪资和链接。
