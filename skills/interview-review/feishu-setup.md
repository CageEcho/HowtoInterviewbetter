# 一键建飞书结构（feishu-setup）

触发：用户说「帮我建面试复盘飞书结构」「初始化面试记录表」「帮我搭面试复盘知识库」。

## 0. 前提
- AI 助手能调用飞书开放平台接口：官方命令行 `lark-cli`，或飞书 MCP / 插件，或直接调 OpenAPI。
- 同学用**自己的账号**在 https://open.feishu.cn/app 创建自建应用，并完成**用户授权**（user_access_token），这样建出的文档归同学本人所有。
- 需要的权限范围（在开放平台「权限管理」里开通）：
  - 知识库：`wiki:wiki`（读写节点）
  - 云文档：`docx:document`（创建/编辑文档）
  - 多维表格：`bitable:app`（创建表格、字段）
  - 可选：`drive:drive`（上传逐字稿 PDF）
- 不要把任何 App ID / Secret / token 写进文档或聊天记录。

## 1. 先问清楚
1. 姓名（必填），学号（可选，填了则命名为「学号-姓名-xxx」）。
2. 目标知识库 `space_id`（在知识库设置里或用 `GET /open-apis/wiki/v2/spaces` 查），以及要挂在哪个父节点下（可选，默认根）。
3. 先 `--dry-run` 把计划给用户确认，再真实创建。

## 2. 要建的节点（前缀 P = 「学号-姓名」或「姓名」）
| # | 标题 | 类型 | 说明 |
|---|---|---|---|
| 0 | P-个人面试记录表&复盘 | docx | 总入口，唯一对外链接，之后不改 |
| 1 | P-个人简历在线综合 | docx | 固定入口，可增内容不可删 |
| 2 | P-个人飞书版简历 | docx | 最新版本 |
| 3 | P-面试表 | bitable | 字段见 `templates/面试表Bitable字段定义.json` |
| 4 | P-面试复盘存档（一次面试一个文档，按模板） | docx | 下挂「复盘模板」 |
| 4.1 | 复盘模板 | docx | 内容取 `templates/复盘文档模板.md` |
| 5 | P-测试题复盘（一次测试题一个文档） | docx | 放标好答案的版本 |
| 6 | P-个人战略（1v1 复盘+面试策略） | docx | |
| 7 | P-个人面试话术文档（自我介绍+打招呼语） | docx | 只一个文档，按问题写 |
| 8 | P-穷尽面试问题汇总（以问题为单位） | docx | 按「公司-场次」只记问题 |
| 9 | P-面试经验沉淀（以条为单位） | docx | 每周复盘 |
简历 PDF 不建节点，提示同学把最新 PDF 作为附件放到总入口第 2 条下。

## 3. 建立步骤
1. **列已有节点**：`GET /open-apis/wiki/v2/spaces/{space_id}/nodes?parent_node_token=...`（分页取全）。同名标题直接复用其 token，**跳过不建**。
2. **建总入口**：`POST /open-apis/wiki/v2/spaces/{space_id}/nodes`，`obj_type=docx`，记下 `node_token`。
3. **依次建子节点**（parent = 总入口），面试表用 `obj_type=bitable`。
4. **配面试表字段**：由 wiki 节点拿到 `obj_token`（即 app_token）→ 列 tables → 对默认表：重命名首列为「公司&团队」，按 JSON 逐个 `POST .../fields` 新增；已存在的同名字段跳过；删除默认生成的空字段/空行（仅限刚新建的表）。
5. **复盘模板**：在「面试复盘存档」下建「复盘模板」，写入 `templates/复盘文档模板.md`。占位要包括：本次面试时间、面试官职位、通义听悟录音链接、逐字稿 PDF（嵌入位置）、问题复盘。以后每场面试复制这份模板，**占位原地填写，不追加到文末**。
6. **写总入口正文**：列出各子文档链接（mention / 链接）+ 规则说明：
   - 一个入口：只提交这一个链接，永不更换。
   - 一岗一行：面试表一个岗位一行，二面只改状态。
   - 一场一档：每场面试新建一份复盘文档，录音放听悟分享链接，逐字稿导出 PDF 嵌入。
   - 测试题一题一档；问题汇总只记问题；经验沉淀以条为单位。
7. **回读核对**：再次列节点，确认 10 个节点 + 复盘模板都在、标题无重复；读面试表字段与 JSON 比对。
8. **输出清单**：每个节点的标题、类型、链接（`https://<你的域名>.feishu.cn/wiki/<node_token>`）。

## 4. 幂等与防重复
- 每一步建之前都先查同名；脚本可重复执行，第二次运行应全部显示「跳过」。
- 写正文只执行一次；若总入口已有内容，先问用户是否覆盖，不重复追加。

## 5. 权限（AI 不要自动改）
建完后提醒同学：先检查没有真实薪资、面试官姓名、公司内部信息，再**自己**在分享设置里设为「互联网获得链接的人可编辑」，并勾选对子页面生效。AI 不调用权限接口放开分享。

## 6. 降级方案
- 无飞书接口：按第 2 节表格手工建；面试表按 JSON 手工加字段；复盘模板手工粘贴。
- 有公开模板：打开模板 →「…」→ 创建副本，**勾选「同时创建子页面的副本」**，再把标题前缀改成自己的。
- 不用飞书：任意文档工具 + 表格按同样结构建即可，方法不绑定工具。

参考脚本：`scripts/setup_feishu.py`（默认 `--dry-run`）。
