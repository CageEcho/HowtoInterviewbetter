# 你的名字-穷尽面试问题汇总（以问题为单位）

> **【🟧 橙色说明框】**
> 只有一个文档：以「公司-面试场次」为最小单位，总结全部面试问题，**只放问题**，不写答案（答案在话术文档）。

> **【🟦 蓝色框（建设攻略）】**
> **建设攻略**
> 1. 每场面试后，从逐字稿里把面试官的问题原样抄过来，按出现顺序编号。
> 2. 每个问题后标类型：开场 / 项目 / 指标 / 业务 / AI 专业 / 场景题 / 流程 / 离职 / 薪资 / 反问。
> 3. 满 5 场后在顶部做统计：哪类问题最多、哪类最常丢分。
> 4. 发现同一问题在不同场次答法不一致，在「口径核对」里登记。
