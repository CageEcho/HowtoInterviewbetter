# 12 各板块建设攻略与示例（附录）

新同学最怕的是：结构建好了，点进去全是空白页，不知道每页该写什么。这一章把总入口下的**每个板块**都拆成三件事：

1. **说明框**：这一页的要求，和班级任务要求框同一个样子（橙色说明框、红色「注意」框、灰色「准备工作」框）。
2. **建设攻略**：第一次写这一页时，一步一步怎么做（蓝色框）。
3. **脱敏示例**：一份写好的参考，照着格式换成你自己的内容。

`skills/interview-review/scripts/setup_feishu.py` 建结构时会把这三样直接写进每个飞书页面，所以新建出来的页面**不是空白**。下表每一行都能点开看示例原文（Markdown 转写版，飞书里是对应颜色的高亮块）。

## 颜色约定

| 颜色 | 用在哪 |
|---|---|
| 🟧 橙色 | 页面要求、任务说明（页面最上面那一块） |
| 🟥 红色 | 「注意 N 点」、概念解释、底层原理、避坑红线 |
| ⬜ 灰色 | 准备工作、设备账号等背景信息 |
| 🟦 蓝色 | 建设攻略（写完自己的内容后可以删） |
| 🟩 绿色 | 可以直接照念的第一人称口播答案、话术补丁 |
| 🟨 黄色 | 深挖追问接招、反问面试官 |

## 示例怎么用

- 页面里带「（示例）」的标题和蓝色攻略框，照着写完自己的内容后删掉即可。
- 「（案例）…」子文档可以一直留着当参照；不想要时建结构时加 `--no-examples`。
- 所有示例都已脱敏：公司是「某软件公司」这类占位，人名、薪资、链接、内部项目名一律不出现。你分享自己的结构前，也按 [11 隐私权限与复制](11-隐私权限与复制.md) 再查一遍。
